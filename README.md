# Neuroscience Learning Foundation

**Open the school:** https://cbaird26.github.io/neuroscience-learning-foundation/

A Khan Academy-style self-study school: 70 courses in five stages, from kindergarten through a complete college degree in
neuroscience and cognitive science to graduate study and research — elementary, middle and high school (including
computational thinking and Python for data and simulation), the neuroscience and cognitive science degree (general
biology, chemistry and physics; genetics; calculus, linear algebra, probability and the statistics of experiments; the
introduction to neuroscience, cellular and molecular neuroscience and neuroanatomy; sensation and perception, learning
and memory, motivation, emotion and sleep; cognitive psychology, cognitive neuroscience, language and development;
neural data analysis, computational neuroscience, cognitive modeling and neuroimaging; philosophy of mind, machine
learning, deep learning and neuroethics; and clinical neuroscience and psychiatry as electives), and graduate study
(theoretical neuroscience, circuits and systems methods, the science of consciousness, brains and machines, research
methods and reproducibility, and a research apprenticeship with qualifying-exam preparation).

Each course has 12 weekly lessons (an article, worked examples, common mistakes, and auto-graded practice and quiz
questions), a week 13–14 project with a review guide, and a cumulative final exam. Skills move through mastery levels
with unit quizzes, a midterm and course challenges, and missed questions go into an error log that brings back a
parallel problem 48 hours later.

## Python in the page

Programming, data analysis and modeling courses include Python exercises that run real Python in the browser, with
nothing to install: the page includes Brython, which follows Python 3.14, with CPython's own json package. Press Run to
try code and Check to grade it against the exercise's tests; a program that runs too long is stopped after a few
seconds. Lesson code that runs here has a "Try it" button, and the Python tab is a scratchpad. The browser's Python has
the whole language and most of the standard library, but not threads, networking or third-party packages such as NumPy
or SciPy, so the exercises simulate neurons and analyze small data sets from scratch in plain Python. Projects are done
on your own computer, where those libraries are available. Your code is never uploaded.

## Using it

Open the site in any modern browser. The whole school is one self-contained page (`index.html`), so you can also save
the page and use it offline.

Progress and the error log are kept only in your own browser and are never uploaded. Keep using the same browser and do
not clear its site data; another browser or device starts fresh. The Tutor button prepares a prompt you can copy into a
chat with Claude.

## Accuracy and fairness

Every course was written and then independently reviewed. Every numeric and typed answer was checked against an
independent computation, every Python exercise's model solution was run against its tests both in standard Python and
in the browser's Python, and every "what does this print?" answer was produced by running the program. On contested
questions, such as how consciousness arises, whether we have free will, how much of the mind is innate, or when animal
research is justified, the lessons present the main views and the strongest arguments on each side and do not tell
learners what to believe. Projects with people use only low-risk tasks with volunteers who agree, and no project
involves animals. Nothing here is medical advice. Laws on neural data, research ethics rules, diagnostic manuals, PhD
programs and the job market change, so check current details before relying on them. Self-study scores do not award
credit, degrees or any credential.
